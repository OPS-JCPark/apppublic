# apppublic

냉장고콕(com.tory.myfridge) 앱의 공개 웹 페이지입니다. GitHub Pages로 게시됩니다.

- `index.html` — 앱 소개 / 링크
- `privacy/index.html` — 개인정보처리방침 (Play Console에 등록하는 URL)

개인정보처리방침은 앱 저장소의 `fridge-app/src/data/privacyPolicy.json`이 원본이며,
`node fridge-app/tools/build-privacy-html.js`로 이 폴더에 다시 만들어집니다. 직접 고치지 마세요.
